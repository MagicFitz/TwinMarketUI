# TwinMarketUI 产品展示动画 · 分镜脚本（中文版）

- **形式**：无旁白，只用界面动画、文字介绍和背景音乐
- **时长**：约 70 秒
- **画幅**：1920×1080，30fps
- **重点**：展示前端界面。所有画面都取自已完成实验的静态页面，不做运行回放。
- **一句话卖点**：在浏览器里完成 TwinMarket 市场模拟的配置、观察和分析。

## 视觉规则

- **画面构成**：界面截图或短录屏放在一个浏览器窗口框里（带圆角和阴影），背景用深色渐变。文字放在窗口旁边，或者叠在窗口上方。
- **文字层级**：
  - 大标题：每个镜头一句，6–10 个字
  - 说明：最多两行，每行不超过 20 个字
  - 标注：用指引线指向界面上的具体区域，2–6 个字
- **镜头语言**：界面基本静止，靠窗口的缓慢推拉、局部放大和高亮框引导视线。点击操作只在需要切页时出现，配一个假光标。
- **节奏**：每个镜头 5–8 秒；文字出现后至少停留 2 秒。
- **转场**：同一空间内用窗口内容横向滑动；切换空间时，窗口先缩小再换内容。
- **配色**：沿用 Studio 的 Radix 主题色作强调色，高亮框和标注线统一用这一个颜色。

## 素材制作方式

- **静态截图为主**：用 Playwright 按镜头逐页截图，可以在现有的 `scripts/capture.mjs` 上扩展。所有推拉、放大、高亮框和标注都在 Remotion 里做。截图使用 1920×1080 视口、`deviceScaleFactor: 2`，放大后文字依然清晰。
- **短录屏为辅**：只有三处需要录屏，录 2–3 秒的片段即可：
  - 镜头 3 的视图切换
  - 镜头 4 的高级参数展开
  - 镜头 8 的 ECharts 入场动画
- **数据准备**：一次已完成的实验，最好是带谣言冲击、约 100 个 Agent、约 10 个交易日。要求各分析子页都有数据，并且至少有一个 Agent 出现“立场转变”。实验列表保留 4–6 个命名整齐的实验。
- **隐私**：不拍设置页；日志和配置里不能出现 Token 或 API Key。
